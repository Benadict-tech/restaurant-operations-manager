# Phase 4 — MySQL and Database Programming

## Learning Objectives

- Design relational schemas (PKs, FKs, constraints, normalization)
- Write SQL: CRUD, WHERE, ORDER BY, GROUP BY, aggregates, JOINs, subqueries
- Use transactions, commit/rollback, indexes
- Connect Python to MySQL with parameterized queries (SQL-injection safe)
- Understand why ORMs exist, then adopt SQLAlchemy + Alembic
