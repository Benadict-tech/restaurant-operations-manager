# Phase 2 — Intermediate Python

## Learning Objectives

- Handle errors with try/except/else/finally and custom exceptions
- Read/write files; work with JSON and CSV (menu exports, supplier lists)
- Use datetime for orders, deliveries, and reports
- Understand iterators, generators, decorators, context managers
- Use *args/**kwargs and type hints fluently
- Master virtual environments, pip, requirements.txt
- Add logging and debug effectively
