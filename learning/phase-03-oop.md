# Phase 3 — Object-Oriented Programming

## Learning Objectives

- Model real entities as classes: Product, Supplier, Order, InventoryItem
- Understand __init__, self, instance vs class variables
- Use instance/class/static methods appropriately
- Apply inheritance, encapsulation, polymorphism, abstraction
- Use @property and composition
- Justify *why* OOP helps a backend project (not just how)
